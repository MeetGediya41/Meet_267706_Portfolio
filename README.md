# Meet Gediya – Personal Portfolio

A responsive personal portfolio website for **Meet Gediya** (B.Tech AI & Data Science, JG University, Ahmedabad), built for the Web Technology internal assessment.

## Sections
Home, About, Education, Skills, Projects (RailQ research, Produce Freshness Checker, this portfolio) and Contact.

## Features
- Light / dark theme toggle (remembered in the browser)
- Mobile hamburger menu
- Contact form with JavaScript validation
- Typing animation, scroll-reveal, scroll progress bar, back-to-top button
- Responsive layout for mobile and laptop using media queries

## Technologies
HTML5, CSS3 (`style.css`), JavaScript (`script.js`), Git & GitHub
